# Destination implementation status

The former unavailable-alert destinations now have working local screens at `/feature`. They follow the existing Gulmeli Fancy Stores orange, white card and mobile typography styles.

| Controls | Working destination |
| --- | --- |
| Product cards | Correct product detail, add to cart, wishlist, seller, reviews |
| Search, campaigns, rankings, Choice | Searchable/filterable catalog, sorting |
| Checkout | Validated address, voucher calculation, saved local order |
| Profile, settings, counters | Saved profile/photo, preferences, wishlist, sellers, voucher wallet |
| Orders and tracking | Saved order history, details, cancellation, buy again; no invented courier status |
| Recent products | Actual browsing history |
| Gems, Freebie, Land, Candy | Local check-in rewards, voucher redemption and counting game |
| Help, Chats, Customer Care | FAQs and saved message drafts; no messages sent |
| Affiliate | Share sheet and saved invitation notes; no commission claims |
| Camera | Camera/library reference selection and manual text/category search |
| Payment Options | Current local checkout payment information |
| Pickup Points | Empty location state with editable delivery address |
| Digital Goods | Empty digital inventory state |
| Offer menu | Shopping shortcuts and working filter reset |

Live commerce, messaging, image recognition and pickup inventory still require external services. See the app README for integration boundaries.
